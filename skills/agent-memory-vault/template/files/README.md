# Files

Attachments, by type. Any agent may **add** a file; nobody edits a file someone else added.

| Folder | For |
|---|---|
| `documents/` | text documents, PDFs, slides, spreadsheets |
| `images/` | screenshots, photos, diagrams |
| `data/` | exports and data sets (processed, not raw dumps) |
| `code/` | snippets and small scripts worth keeping |
| `archive/` | old versions, kept whole |
| `_unsorted/` | drops from a phone or a download; the core writer files them |

Name: `YYYY-MM-DD-what-it-is.ext`. Never a key file, a wallet file or an `.env` file, here or anywhere in the vault.

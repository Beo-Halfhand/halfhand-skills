# Reports

Finished reports from one-off sessions (a coding tool run, a script, a research task). Name: `YYYY-MM-DD-HHMM-short-task-name.md`.

Start each report with frontmatter so it can be found later:

```yaml
---
type: report
topic: the topic home this belongs to
summary: "one line"
updated: YYYY-MM-DD
---
```

Names of keys only, never values. A report that changes what is true updates the topic home too, or asks for it in [[INBOX]].

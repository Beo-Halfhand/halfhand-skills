# Topic homes

One note per subject: what is true **now** about it. The day logs say what happened; a topic home says where things stand.

- **Third time gets a home.** A subject that shows up in the day logs on a third separate day gets a note here.
- Link it from the "Now" table in [[ROUTER]] and from [[HOME]].
- Name: lowercase with hyphens, `kitchen-remodel.md`, not `Kitchen Remodel.md`.
- Start each home with a one-line summary and an "As of" date. End it with links to the notes it touches.
- One writer per home: whoever created it, unless [[RULES]] says otherwise. Others link to it and send changes through [[INBOX]].

Delete [[example-project]] once you have a real one.
